# Check

Read `stack.md`, `voice-queue.md`, `learnings/index.md`, and the responsibility pages those files point at. Produce one short list. Cap it at five. If nothing qualifies, say that and stop.

Look only at:

1. Specs marked unverified, or `sources` that changed since the last check and were not triaged.
2. Voice holds whose count went up, and passes still waiting on a link.
3. Learnings from the last seven days that change a boundary, a rung, or whether something gets a page.
4. A promise on a responsibility page that the week's evidence contradicts.

For each of the five, one line: what it is, which skill to run next (triage or learn), and the file or link. Do not file issues. Do not rewrite the manual. Do not open a sixth item.
