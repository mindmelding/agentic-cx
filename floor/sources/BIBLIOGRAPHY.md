# Reading list

The sources this canon leans on most, and the one idea taken from each. Cases are in [`failures/`](../../failures/README.md) with their own sources.

| Source | What we took |
|---|---|
| *Unreasonable Hospitality*, Will Guidara (2022) | The 95/5 rule (p07) and one-size-fits-one (p08) |
| *Setting the Table*, Danny Meyer (2006) | Collecting dots: the write path of the [context contract](../context/CONTRACT.md) |
| Ritz-Carlton Gold Standards | Real authority with a ceiling, which became `guardrails/authority.md` (p18) |
| *The Power of Moments*, Chip and Dan Heath (2017) | Elevation, insight, pride, connection, in [`delight/`](../delight/PHILOSOPHY.md) |
| *The Effortless Experience*, Dixon, Toman, DeLisi (2013) | Remove effort before adding delight (p06) |
| *Never Split the Difference*, Chris Voss (2016) | Label, don't claim, in [`voice/`](../voice/VOICE.md) |
| *On Apology*, Aaron Lazare (2004) | Apologize once, specifically (p04) |
| *The Mom Test*, Rob Fitzpatrick (2013) | A feature request is a conversation about the job (p14) |
| *Never Lose a Customer Again*, Joey Coleman (2018) | The first hundred days, in [onboarding](../../responsibilities/onboarding.md) |
| Lincoln Murphy, Sixteen Ventures | Desired outcome in their words: row 8 of the contract |
| [Building effective agents](https://www.anthropic.com/research/building-effective-agents), Anthropic | Keep the always-on context small; load the rest on demand |
| [Agent Skills](https://agentskills.io) | Playbooks as skills, loaded when the moment matches |
